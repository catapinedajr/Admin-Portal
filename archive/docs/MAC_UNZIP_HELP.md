# How to Open .tar.gz Files on Mac

## Option 1: Use Terminal (Recommended)
1. Open Terminal on your Mac
2. Navigate to where you downloaded the file
3. Type: `tar -xzf hodlearn-ios-complete.tar.gz`
4. Press Enter

## Option 2: Install The Unarchiver (Free App)
1. Download "The Unarchiver" from Mac App Store
2. Once installed, double-click the .tar.gz file
3. It will extract automatically

## Option 3: Use Built-in Archive Utility
1. Right-click on the .tar.gz file
2. Choose "Open With" → "Archive Utility"
3. It should extract to a folder
