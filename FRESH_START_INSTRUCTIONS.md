## Setup on Your Mac:

### 1. Download and Extract
```bash
# Download hodlearn-ios-project.zip from Replit
# Double-click the ZIP file on Mac to extract it
# Or use Terminal:
unzip hodlearn-ios-project.zip
cd hodlearn-ios-project
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Deploy to iOS
```bash
# Make script executable
chmod +x ios-deploy.sh

# Build and open in Xcode
./ios-deploy.sh
```

### 4. Xcode Configuration
When Xcode 16.4 opens:
1. Select your Apple Developer team
2. Verify Bundle ID: `com.hodlearn.app`
3. Archive and upload to App Store Connect
