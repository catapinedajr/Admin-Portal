# HODLearn Content Import Template

## Successfully Proven Import Process

This template demonstrates the proven workflow for importing content generated by external tools (like Claude/Grok) into HODLearn's database structure.

## Database Structure Overview

### Content Tables (in dependency order):
1. **content_days** - Main day metadata (day_index, title, theme, etc.)
2. **content_set_up_questions** - 3 curiosity-building questions per day
3. **content_lessons** - Main educational content with takeaways
4. **content_quizzes** - 4 comprehension questions per day

## Import Process Template

### Step 1: Create Day Entry
```sql
INSERT INTO content_days (day_index, title, reading_level, cultural_stage, theme, is_active, is_approved) 
VALUES ([DAY_NUMBER], '[DAY_TITLE]', 'high_school', 'mainstream', '[THEME]', true, true);
```

### Step 2: Insert Setup Questions (3 required)
```sql
INSERT INTO content_set_up_questions (day_id, title, content, category, icon, order_index) VALUES
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_1]', '[DESCRIPTION_1]', '[CATEGORY_1]', '[ICON_1]', 0),
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_2]', '[DESCRIPTION_2]', '[CATEGORY_2]', '[ICON_2]', 1),
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_3]', '[DESCRIPTION_3]', '[CATEGORY_3]', '[ICON_3]', 2);
```

### Step 3: Insert Lesson Content
```sql
INSERT INTO content_lessons (day_id, title, content, key_takeaways, why_it_matters, estimated_read_time) 
VALUES (
  (SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), 
  '[LESSON_TITLE]', 
  '[LESSON_CONTENT]',
  '[JSON_ARRAY_OF_TAKEAWAYS]',
  '[WHY_IT_MATTERS_TEXT]',
  [READ_TIME_MINUTES]
);
```

### Step 4: Insert Quiz Questions (4 required)
```sql
INSERT INTO content_quizzes (day_id, question, options, correct_answer, explanation) VALUES
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_1]', '[OPTIONS_JSON_ARRAY]', [CORRECT_INDEX], '[EXPLANATION_1]'),
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_2]', '[OPTIONS_JSON_ARRAY]', [CORRECT_INDEX], '[EXPLANATION_2]'),
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_3]', '[OPTIONS_JSON_ARRAY]', [CORRECT_INDEX], '[EXPLANATION_3]'),
((SELECT id FROM content_days WHERE day_index = [DAY_NUMBER]), '[QUESTION_4]', '[OPTIONS_JSON_ARRAY]', [CORRECT_INDEX], '[EXPLANATION_4]');
```

## Content Framework Requirements

### Setup Questions (3 per day):
- Build financial urgency and Bitcoin curiosity
- Use everyday language, not technical jargon
- Categories: Financial Awareness, System Understanding, Bitcoin Solution
- Icons: DollarSign, TrendingDown, Shield, etc.

### Lesson Content:
- 300-500 words, 8th grade reading level
- "Conviction Through Curiosity" approach
- Start with financial problems, lead to Bitcoin solutions
- Include concrete examples and real numbers
- End with "And this is HODLearn" (once per day maximum)

### Quiz Questions (4 per day):
- Test actual lesson comprehension
- Options as JSON array: ["Option A", "Option B", "Option C", "Option D"]
- correct_answer as 0-based index (0=A, 1=B, 2=C, 3=D)
- Explanations reinforce key learning points

### Key Takeaways (3 required):
- JSON array format: ["Point 1", "Point 2", "Point 3"]
- Under 12 words each
- Use everyday language, not technical terms

### Why It Matters:
- Emphasize financial self-defense importance
- Connect to real-world financial goals
- Explain Bitcoin's relevance to the lesson

## Verification Process

After import, verify with:
```sql
-- Check record counts
SELECT 'content_days' as table_name, COUNT(*) as records FROM content_days
UNION ALL
SELECT 'content_set_up_questions', COUNT(*) FROM content_set_up_questions
UNION ALL
SELECT 'content_lessons', COUNT(*) FROM content_lessons
UNION ALL
SELECT 'content_quizzes', COUNT(*) FROM content_quizzes;

-- Verify specific day content
SELECT 
  cd.day_index,
  cd.title as day_title,
  cl.title as lesson_title,
  (SELECT COUNT(*) FROM content_set_up_questions csq WHERE csq.day_id = cd.id) as setup_questions,
  (SELECT COUNT(*) FROM content_quizzes cq WHERE cq.day_id = cd.id) as quiz_questions
FROM content_days cd
LEFT JOIN content_lessons cl ON cd.id = cl.day_id
WHERE cd.day_index = [DAY_NUMBER];
```

## Bulk Import Process

For importing multiple days at once, use the JSON format in `CLAUDE_BULK_IMPORT_FORMAT.md`:

1. Generate JSON with Claude using the bulk format
2. Save as `.json` file (e.g., `week2-content.json`)
3. Run: `node bulk-import.js week2-content.json`
4. Verify import with database queries

This template enables rapid content creation using external AI tools while maintaining HODLearn's educational framework and database integrity.
