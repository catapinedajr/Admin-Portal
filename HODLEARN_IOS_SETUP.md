# HODLearn iOS App - Native Setup

## Quick Start (5 minutes)

1. **Open Xcode** → Create New Project
   - iOS → App
   - Product Name: `HODLearn`
   - Bundle ID: `com.hodlearn.app`
   - Language: Swift
   - Interface: SwiftUI

2. **Replace 3 Files:**
   - Download `ContentView.swift` from ios-export folder → Replace default ContentView.swift
   - Download `HODLearnApp.swift` from ios-export folder → Replace default HODLearnApp.swift  
   - Download `Info.plist` from ios-export folder → Replace default Info.plist

3. **Build & Run** → Your HODLearn iOS app loads https://hodlearnbeta.replit.app

## What This Creates:
- Native iOS app with WKWebView
- Loads your deployed HODLearn directly
- Full functionality (home page, learn sections, simulators)
- Ready for TestFlight beta testing

## Files to Download from Replit:
- `ios-export/ContentView.swift`
- `ios-export/HODLearnApp.swift` 
- `ios-export/Info.plist`

This bypasses all Capacitor issues and gives you a clean, working iOS app.
